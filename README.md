# BCup

Next.js App Router project using TypeScript, Tailwind CSS, ESLint, and pnpm.
The UI uses the [Lime design system](https://design.how/systems/lime). Follow
[the local Lime skill](.agents/skills/lime/SKILL.md) for UI changes.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000. The product brief is in [task.md](task.md).

## Checks

```bash
pnpm lint
pnpm lint:lime
pnpm typecheck
pnpm build
```
